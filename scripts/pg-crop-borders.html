Picture Guide — strip borders, standardise sizes

Photos taken out of the printed guide carry a border drawn into the image itself: a 3px line with a 1px antialias fringe outside it, and on the red ones a second fringe inside too, so black borders are 4px and red ones are 5px. The app draws its own frame and its own OPTIONAL flag, so that border lands as a second outline just inside the first. This finds the border on each photo, trims it off, and puts the trimmed photo back under the same filename — nothing in the database changes. It then centre-crops every photo to one size, the largest the whole batch can share, so the board can set a single frame shape and have nothing left over.

You do not have to tell the app the size afterwards. The board measures its own first photograph and sets the frame to it, so each sheet gets its own shape — the iPhone batch is 591×565 and the Android one 563×593, one wider than tall and one taller than wide. What this tool is for is making the photos within one sheet agree with each other; the odd one out is the one that ends up letterboxed. Edit NAMES below for a new batch.

Scan first and read the border column. A batch whose borders were already removed before saving should report none on every row — that is the expected result, not a failure, and it means the crop is a pure centring. Any row claiming a border on a photo you know is clean is a reason to stop rather than to continue: this trims pixels off originals and puts them back under the same name.
